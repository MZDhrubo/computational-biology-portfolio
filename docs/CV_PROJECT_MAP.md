# CV-to-portfolio map

This note maps broad areas in my CV to material that can safely be shown in a public portfolio. It is not intended to reproduce unpublished project methods, datasets, candidate lists, or results.

| CV area | Public evidence in this repository | What is not claimed |
|---|---|---|
| Python and data processing | Three small command-line utilities with input validation and tests | That these utilities were used to generate a manuscript's results |
| Bulk/single-cell RNA-seq training | Synthetic count-matrix QC and exploratory PCA example | Production RNA-seq differential-expression analysis or a biological finding |
| Protein structure modelling/validation | PDB inventory utility and structural-workflow notes | A new protein model, a completed validation benchmark, or a claim of structural accuracy |
| Docking, virtual screening, ADMET | Transparent processing of a synthetic docking/descriptors table | New docking runs, ADMET predictions, hit discovery, or therapeutic efficacy |
| Morbillivirus/Chikungunya immunoinformatics | Workflow checklist describing major analysis stages | Original epitopes, vaccine constructs, immune-simulation outputs, or unpublished results |
| GROMACS training | Reproducibility and reporting checklist | A completed independent molecular-dynamics study unless separately documented and verified |
| Fish genetics and functional genomics | Separate SOX/DMRT phylogeny portfolio and project-specific documentation, where approved for release | Release of any data or outputs withheld from the current manuscript |

The public demonstration data are synthetic. A CV skill or research contribution should only be described as completed work when supported by the user's actual experience and evidence.
