# Additional CV areas represented here

This repository is intended to sit alongside a separate SOX/DMRT phylogeny repository. It focuses on public, synthetic demonstrations related to other areas in my CV:

- exploratory transcriptomics quality control;
- protein structure file inspection;
- transparent docking-score and molecular-descriptor table processing;
- immunoinformatics workflow documentation;
- molecular-dynamics reproducibility practices.

The repository is not intended to imply that every demonstrated utility was used in a manuscript, that every CV-listed tool was used independently, or that the synthetic data are scientific findings. Research-specific source code and data should only be published after the relevant co-authors, employer, or institution have cleared them for release.
