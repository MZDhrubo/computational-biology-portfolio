# Immunoinformatics workflow: public overview

My CV describes work related to in-silico multi-epitope vaccine research, including Morbillivirus and Chikungunya topics. The original sequences, epitope selections, constructs, docking outputs, immune-simulation results, and manuscript-specific decisions are intentionally excluded from this public repository.

A reproducible project may document the following stages, where appropriate to its study design:

1. Define the target pathogen, biological question, and inclusion criteria for target proteins.
2. Record source databases, accession/version identifiers, retrieval dates, and sequence provenance.
3. Evaluate candidate epitopes with clearly identified tools and versions.
4. Document antigenicity, allergenicity, toxicity, conservation, and population-coverage assessments, including limitations of each prediction.
5. Record construct design choices and link each component to its source and rationale.
6. Track structure prediction and quality assessment separately; do not treat a predicted structure as experimentally confirmed.
7. Record docking setup, reference structures, grid/search settings, controls, and scoring limitations.
8. If immune simulation or molecular dynamics is used, preserve configuration, random seeds where applicable, tool versions, logs, and analysis choices.
9. Separate computational predictions from experimental evidence and biological conclusions.

This document is a general reproducibility checklist. It does not claim that each stage was performed for every project listed in my CV, and it does not contain unpublished study results.
