# Contributions and transparency

This repository is a public-facing companion portfolio for computational biology skills listed in my CV. It contains demonstration utilities and synthetic data; it is not a release of the source code or findings from an unpublished manuscript.

Before presenting this repository in an application, I will be prepared to explain each script, its assumptions, the tests, and the limitations. I will describe my own contributions to each underlying research project accurately and separately from the demonstration code here.

Where AI tools have assisted with drafting, debugging, or refactoring, I will disclose that assistance when required by the relevant institution, employer, collaborator, or application process. No authorship, publication, validation, or scientific result is claimed solely because a file appears in this repository.
